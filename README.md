# CECE Study Pro — Counselor Prep

A gamified study app for the Counselor Education Comprehensive Examination (CECE). Built with React + Vite.

## Features
- 173 practice questions across all 8 CECE domains
- 23 flashcards with key concepts
- Timed challenge mode (30s per question)
- Domain score tracking
- Points, streaks, and progress tracking

## Getting Started

```bash
npm install
npm run dev
```

## Deploying to Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) and sign in with GitHub
3. Click "Import Project" and select this repo
4. Click "Deploy" — done!
